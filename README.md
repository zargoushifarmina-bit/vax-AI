# VaxAI Pro

دموی طراحی واکسن — نسخه‌ی نهایی و مستقل (بدون نیاز به سرور یا کلید API).

## اجرا / انتشار

این پروژه فقط یک فایل `index.html` است، پس هر روش زیر کار می‌کند:

### گزینه ۱ — GitHub Pages (رایگان)
1. این ریپازیتوری را روی گیت‌هاب Push کن
2. برو به Settings → Pages
3. زیر Source، شاخه (Branch) اصلی (`main`) و پوشه `/ (root)` را انتخاب کن
4. بعد از چند دقیقه لینک زنده در همان صفحه ظاهر می‌شود (چیزی شبیه `username.github.io/repo-name`)

### گزینه ۲ — باز کردن مستقیم
فایل `index.html` را می‌توان مستقیم در هر مرورگری هم باز کرد (بدون نیاز به هاست)، چون همه‌چیز (React، استایل، دیتا) داخل همین یک فایل است و از CDN عمومی React لود می‌شود.

## نکات فنی
- بدون build step — React و Babel به‌صورت مستقیم از CDN (`unpkg.com`) لود می‌شوند
- بدون هیچ کتابخانه‌ی نموداری بیرونی (نمودارها با کد داخلی نوشته شده‌اند)
- داده‌های پاتوژن‌ها از پیش تعریف‌شده (demo data) هستند؛ این نسخه یک Proof-of-Concept UI است و به دیتابیس‌های زنده (NCBI/UniProt/IEDB) متصل نیست
